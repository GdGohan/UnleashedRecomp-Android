# Unleashed Recomp Android 0.6.1

This release adds a bundled driver for Snapdragon 8 Elite, brings back the audio presets that were missing from 0.6.0, fixes DLC imports and GPU hangs, lets each touch control be resized, and redesigns the launcher.

## Graphics

- **Adreno 8xx driver for Snapdragon 8 Elite.** A source-built Mesa 26.3 Turnip with a fix for the newer Qualcomm gralloc, which otherwise leaves the whole image garbled on Adreno 830. Auto selects it on SM8750 devices unless an imported driver is chosen, and it always renders with `TU_DEBUG=sysmem,nobin`. On Adreno 830 it measured about 12 ms of GPU time per frame at 100% resolution, compared with about 26 ms on the stock driver. Other Adreno 8xx GPUs can select it manually; it has only been validated on Adreno 830.
- **High refresh rate displays.** The game requests the display's fastest mode and passes the FPS option to Android, so FPS settings above 60 are no longer capped at 60 by vsync on 120 Hz phones.
- **Fewer frozen images on Adreno 6xx** ([#170](https://github.com/SansNope/UnleashedRecomp-Android/issues/170)). Some Turnip builds return early from an unlimited GPU wait; the game now waits again instead of reusing buffers the GPU is still drawing. If the GPU driver stops responding, the game explains that and closes instead of freezing the image while audio continues. Choose another driver in the launcher if this happens.
- A saved **Adreno 8xx Experimental** choice from 0.5.3 opens as the new **Adreno 8xx** driver.

## Audio

- **Audio presets are back** ([#171](https://github.com/SansNope/UnleashedRecomp-Android/issues/171)). 0.6.0 was built without the 0.5.3 audio work. The launcher's **Audio** section again offers **Default**, **AYN** for handhelds that start without sound, and the experimental **POCO F8 Ultra (low latency)** profile, together with the 0.5.3 audio-clock and Bluetooth/background recovery improvements.

## Installation

- **DLC imports with a title update included** ([#166](https://github.com/SansNope/UnleashedRecomp-Android/issues/166)). When the game is already installed, a title update or game dump staged next to the DLC is ignored and the DLC packs are installed. If a DLC import still fails, the app shows the error, removes the staged copies and starts the installed game; previously every launch failed until `to_install` was cleared by hand.

## Launcher and touch controls

- **Resize individual controls** ([#169](https://github.com/SansNope/UnleashedRecomp-Android/issues/169)). In the layout editor, tap a control and use **-** / **+** to change only its size; tap empty space to resize the whole set as before.
- **Fixed opening the layout editor while a game was running in the background.** The editor did not appear, and the leftover request opened the editor instead of the game on the next launch.
- **Redesigned launcher.** A dark, landscape screen keeps the game status, the selected driver and audio preset, **Launch game** and quick **Controls / Mods / Files** buttons on the left, with settings grouped into sections on the right. Update checks show a banner, and a new **Exit** action also closes a game left running in the background. The launcher and mod screens run full screen, in landscape and under the display cutout, and the app identifies itself to Android as a game. These parts follow **vladector**'s launcher proposal ([PR #154](https://github.com/SansNope/UnleashedRecomp-Android/pull/154)).

Thanks to **vladector** for the launcher proposal, and to everyone who reported the DLC, audio, Adreno 650 and touch-control problems.

## Updating

Install `UnleashedRecomp_0.6.1.apk` over the existing app. The package ID and signing certificate match the previous releases, so game files, saves, mods and settings remain in place. The APK is an ARM64 Release build for **Android 10 or newer**, with version code **22**. It also installs over the 0.6.1 test builds, which used version code 21.
